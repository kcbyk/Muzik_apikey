💻 Projelerine Entegre Et

Ürettiğin API anahtarını x-api-key başlığı olarak ekleyerek hemen müzik üretebilirsin.

curl -X POST https://muzik-apikey.onrender.com/generate-beat \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "duygusal akustik gitar beat, trap ritim, sakin melodi",
    "title": "Akustik Beat",
    "make_instrumental": true
  }'
